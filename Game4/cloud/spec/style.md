# Style guide

- 32 px tiles, 14-row screens (world height 448); stage palettes drive tile colours over generated parallax backdrops.
- Hero and bosses are the eight 萌友 chibi sprites; enemies: hard-hat walker, eye drone, dome turret.
- Mega-Man-style vertical energy bars; UI in Traditional Chinese.
