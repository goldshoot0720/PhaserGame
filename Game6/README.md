# 萌友戰棋・八方對決

以 Phaser 3 製作的棋盤式回合制戰略遊戲，使用 `assets/` 中的 8 張角色圖。

## 執行
```
cd Game6
python3 -m http.server 8766
```
然後開啟 http://localhost:8766/ （不能直接雙擊 index.html，瀏覽器會擋下圖片讀取）。

## 玩法
- 從 8 位角色中選 4 位出戰，其餘 4 位由電腦操控
- 點我方角色 → 點藍色格子移動 → 選擇 攻擊／治療／待命
- 右鍵或 Esc 取消，E 結束回合
- 森林 +2、山岳 +3、民房 +1 防禦；站在民房上每回合恢復 5 HP
- 攻擊後若在對方射程內會遭到反擊
