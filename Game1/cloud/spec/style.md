# Style guide

- Catcher's-view batting/pitching in the Power Pro tradition.
- Cast: the eight 萌友 characters (汐音、小冰、光哉、阿翔 = 藍鯨隊; 小花、書白、緋音、澪 = 貓咪隊) as generated chibi pixel sprites.
- UI text in Traditional Chinese, drawn through unicodeText with dark outlines.
- Palette: stadium greens/browns, team blue #2a6fdb vs team red #e0503a, gold #ffe066 highlights.
