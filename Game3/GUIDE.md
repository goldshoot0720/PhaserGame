## 遊戲目標

選一名車手和一條賽道，與七名電腦車手競跑三圈；以抵達終點的時間決定排名。

## 操作方式

| 操作 | 用途 |
| --- | --- |
| ↑／W | 加速 |
| ↓／S | 煞車 |
| ←→／A、D | 轉向 |
| 按住 Shift 並轉向 | 甩尾蓄積小加速 |
| Space | 使用持有道具 |
| Esc | 退出比賽 |

## 手機與平板

觸控裝置會顯示方向鍵、確認與本作專用動作按鈕，可同時按住移動與動作。直接點選畫面上的選單、角色、卡牌或棋盤；大亂鬥可拖曳瞄準／射擊圓盤。橫向畫面較大，切換到背景會自動暫停，回來後按「繼續」。

## 新手第一場

1. 先選車手，再選海洋城市、冰雪企鵝村或霓虹夜城。新手先從海洋城市熟悉路線。
2. 持續加速，彎前調整車身位置。避免衝出路緣，離開路面會明顯降速。
3. 速度超過半速後按 Shift 配合轉向甩尾，放開 Shift 釋放小加速。
4. 碰到道具箱取得一件道具，按 Space 使用；第三圈衝線後查看排名與最佳成績。

## 規則與畫面資訊

- 共有八位車手，速度、加速度與操控倍率不同；1.00 為基準。
- 甩尾約 0.8 秒形成藍色加速，約 1.6 秒形成橘色加速。先保持在路面上，再延長蓄力。
- 路外速度上限降至通常最高速度的 45%。彎道會把高速車向外推。
- 衝刺魚加速、香蕉皮留在後方、泡泡彈追蹤對手、無敵星提供無敵。後段名次更容易抽到強力道具，但不是保證。
- 冰雪企鵝村操控係數 0.82，海洋城市 1.00，霓虹夜城 0.95。最佳時間保存在目前瀏覽器。

## 常見問題

### 按 Shift 為什麼沒有加速？

需要足夠速度、同時轉向並蓄積時間，放開後才觸發。

### 為什麼領先時拿不到無敵星？

道具機率依名次調整，領先者仍可能抽到，但權重較低。
